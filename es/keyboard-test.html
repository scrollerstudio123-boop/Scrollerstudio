Problemas de teclado comunes que este test puede detectar

SíntomaCausa probable
Una tecla no se ilumina por mucho que la pulsesSwitch desgastado, suciedad bajo la tecla o un contacto de membrana dañado debajo.
Una tecla se registra dos veces con una sola pulsaciónRebote del switch — el contacto se rompe y rehace brevemente en una sola pulsación, y el navegador lo lee como dos pulsaciones.
Una tecla se queda "atascada" y se repite solaPuede ser una tecla físicamente atascada o una combinación de modificador retenida por otra app — intenta pulsar la tecla de nuevo con firmeza para liberarla.
Varias teclas dejan de funcionar solo al pulsarlas juntasSuele ser una limitación de ghosting/rollover — la mayoría de teclados solo detecta de forma fiable un número limitado de pulsaciones simultáneas.

Preguntas frecuentes

¿Por qué no se registran algunas teclas (como atajos del navegador)?

Ciertas combinaciones, como Ctrl+W o Ctrl+T, son interceptadas por el propio navegador para gestionar pestañas y ventanas antes de que la página llegue a verlas. Es una restricción a nivel de navegador, no un fallo de tu teclado.

¿Qué significa "repeticiones detectadas"?

Cuenta los eventos de pulsación que se disparan por mantener una tecla presionada, no por una segunda pulsación genuina. Un número pequeño es normal — los navegadores repiten una tecla mantenida automáticamente tras un breve retraso. Lo que vale la pena investigar es si aparecen repeticiones sin que mantengas nada pulsado.

¿Funciona este test con un teclado en pantalla o virtual?

Sí, siempre que el teclado virtual envíe eventos de tecla estándar al navegador, pero el diseño de esta página está pensado para las posiciones de un teclado físico, así que la cuadrícula visual puede no coincidir exactamente con un diseño virtual.

Las teclas de función de mi portátil se comportan de forma distinta a la esperada.

Muchos portátiles requieren una combinación con la tecla Fn para enviar una señal de tecla de función estándar en vez de un atajo de hardware (brillo, volumen, etc.). Revisa la configuración de teclado de tu sistema si las teclas F no se registran como esperabas.
