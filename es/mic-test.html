Por qué un micrófono puede parecer conectado pero no funcionar

Entrada equivocada seleccionada

Tu sistema o navegador puede usar por defecto un micrófono distinto al que esperas — revisa la configuración de sonido del sistema si la traza se queda plana.

Silenciado a nivel de hardware

Muchos auriculares y micrófonos USB tienen un botón de silencio físico o un indicador LED — vale la pena revisarlo antes de asumir un fallo de software.

Permiso bloqueado

Si tu navegador denegó antes el acceso al micrófono para este sitio, tendrás que restablecer ese permiso en la configuración del sitio de tu navegador antes de que pueda pedirlo de nuevo.

Nivel demasiado bajo

Una traza débil pero presente suele significar que la ganancia está baja — revisa el volumen de entrada de tu sistema antes de sospechar un fallo de hardware.

Preguntas frecuentes

¿Se graba o se envía mi audio a algún sitio?

No. La forma de onda se dibuja directamente a partir de la señal en vivo de tu micrófono usando la Web Audio API — nada se graba, guarda o transmite.

¿Por qué el navegador pide permiso cada vez?

El acceso al micrófono se concede por sitio y, en algunos navegadores, por sesión, por motivos de privacidad. Puedes hacerlo persistente desde la configuración del sitio en tu navegador si prefieres que no se te vuelva a preguntar.

La forma de onda salta o se corta — ¿es normal?

Pueden ocurrir parpadeos breves por el procesamiento de ruido de fondo que aplica tu sistema automáticamente. Un micrófono que se corta por completo y de forma repetida suele apuntar a una conexión suelta o un problema de controlador.
